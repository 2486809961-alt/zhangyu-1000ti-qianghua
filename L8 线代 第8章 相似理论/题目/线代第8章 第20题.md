# 第8章 第20题

> [!question] 题干
> 在某一核反应堆中有 $\alpha$ 与 $\beta$ 两种粒子，若每秒钟 1 个 $\alpha$ 粒子分裂成 3 个 $\beta$ 粒子，且 1 个 $\beta$ 粒子分裂成 2 个 $\beta$ 粒子与 1 个 $\alpha$ 粒子．设在 $t=0$ 时刻，该反应堆中只有 1 个 $\alpha$ 粒子，记 $a_n,b_n$ 分别表示 $t=n$ 秒时 $\alpha$ 粒子、$\beta$ 粒子的个数．
>
> (1) 证明 $\begin{bmatrix}a_n\\a_{n-1}\end{bmatrix}=\begin{bmatrix}2&3\\1&0\end{bmatrix}^{n-1}\begin{bmatrix}0\\1\end{bmatrix}$；
> (2) 求 $t=n$ 秒时反应堆中的粒子总数 $a_n+b_n$．

> [!success] 答案
> (1) 见下；(2) $a_n+b_n=3^{n}$．

## 解析要点
1. **切入点**：先把"粒子分裂"翻译成递推式（这是应用题的第一步，也最容易错）。
   - 每 1 个 $\alpha$ 变成 3 个 $\beta$ ⇒ 第 $n$ 秒的 $\beta$ 数中，来自上秒 $\alpha$ 的部分是 $3a_{n-1}$；
   - 每 1 个 $\beta$ 变成 2 个 $\beta$ + 1 个 $\alpha$ ⇒ 来自上秒 $\beta$ 的 $\beta$ 数是 $2b_{n-1}$，$\alpha$ 数是 $b_{n-1}$。
   故
   $$a_n=b_{n-1},\qquad b_n=3a_{n-1}+2b_{n-1},\qquad a_0=1,\ b_0=0 .$$
2. **关键步骤（1）消去 $b$**：由 $a_n=b_{n-1}$ 得 $b_{n-1}=a_n$，代入 $b_n$ 的式子（下标整体降 1）：
   $$a_{n-1}=b_{n-2},\qquad b_{n-1}=3a_{n-2}+2b_{n-2}=3a_{n-2}+2a_{n-1},$$
   而 $a_n=b_{n-1}$，故
   $$a_n=2a_{n-1}+3a_{n-2}\qquad(n=2,3,\cdots).$$
   写成矩阵形式：
   $$\begin{bmatrix}a_n\\a_{n-1}\end{bmatrix}=\begin{bmatrix}2&3\\1&0\end{bmatrix}\begin{bmatrix}a_{n-1}\\a_{n-2}\end{bmatrix}=\cdots=\begin{bmatrix}2&3\\1&0\end{bmatrix}^{n-1}\begin{bmatrix}a_1\\a_0\end{bmatrix}.$$
   又 $a_1=b_0=0,\ a_0=1$，故
   $$\begin{bmatrix}a_n\\a_{n-1}\end{bmatrix}=\begin{bmatrix}2&3\\1&0\end{bmatrix}^{n-1}\begin{bmatrix}0\\1\end{bmatrix}.$$
3. **关键步骤（2）算幂**：记 $A=\begin{bmatrix}2&3\\1&0\end{bmatrix}$，
   $$|\lambda E-A|=\begin{vmatrix}\lambda-2&-3\\-1&\lambda\end{vmatrix}=\lambda^{2}-2\lambda-3=(\lambda+1)(\lambda-3),$$
   得 $\lambda_1=-1,\ \lambda_2=3$。特征向量：$\lambda_1=-1$ 时 $(-E-A)x=0$ 得 $\xi_1=[-1,1]^{\mathrm T}$；$\lambda_2=3$ 时 $(3E-A)x=0$ 得 $\xi_2=[3,1]^{\mathrm T}$。令 $P=\begin{bmatrix}-1&3\\1&1\end{bmatrix}$，则 $P^{-1}=-\dfrac14\begin{bmatrix}1&-3\\-1&-1\end{bmatrix}$，$P^{-1}AP=\mathrm{diag}(-1,3)$。于是
   $$A^{n-1}=P\begin{bmatrix}(-1)^{n-1}&0\\0&3^{n-1}\end{bmatrix}P^{-1}=\frac14\begin{bmatrix}(-1)^{n}&3^{n}\\(-1)^{n-1}&3^{n-1}\end{bmatrix}\begin{bmatrix}-1&3\\1&1\end{bmatrix},$$
   代入 $\begin{bmatrix}0\\1\end{bmatrix}$ 得
   $$\begin{bmatrix}a_n\\a_{n-1}\end{bmatrix}=\begin{bmatrix}\frac34(-1)^{n}+\frac14 3^{n}\\[4pt] \frac34(-1)^{n-1}+\frac14 3^{n-1}\end{bmatrix}.$$
4. **关键步骤（3）求和**：由 $b_n=a_{n+1}$（因为 $a_{n+1}=b_n$）得
   $$a_n+b_n=a_n+a_{n+1}=\Big[\tfrac34(-1)^{n}+\tfrac14 3^{n}\Big]+\Big[\tfrac34(-1)^{n+1}+\tfrac14 3^{n+1}\Big].$$
   第一、三项的 $(-1)^n$ 与 $(-1)^{n+1}$ 反号相消，剩余
   $$a_n+b_n=\tfrac14 3^{n}+\tfrac14\cdot 3\cdot 3^{n}=3^{n}.$$
5. **结果与验算**：$a_n+b_n=3^n$。核验小 $n$：$n=0$ 时总数 $1=3^0$ ✓；$n=1$ 时 $a_1=0,\ b_1=3a_0+2b_0=3$，总数 $3=3^1$ ✓；$n=2$ 时 $a_2=b_1=3,\ b_2=3a_1+2b_1=6$，总数 $9=3^2$ ✓。
   **更妙的验算（守恒视角）**：每个 $\alpha$ 提供 3 个 $\beta$、每个 $\beta$ 提供 2 个 $\beta$ 与 1 个 $\alpha$，而 $a_n=b_{n-1}$ 且 $b_n=3a_{n-1}+2b_{n-1}$ ⇒ $a_{n+1}+b_{n+1}=3a_n+3b_n$，故总数每次乘 3，从 $1$ 出发即得 $3^n$。

> [!info] 考点
> - 应用题建模：**"分裂/转移"计数 → 一阶递推 → 二阶线性递推 → 矩阵幂**
> - 二阶递推 $a_n=pa_{n-1}+qa_{n-2}$ 的矩阵化：$\begin{bmatrix}a_n\\a_{n-1}\end{bmatrix}=\begin{bmatrix}p&q\\1&0\end{bmatrix}\begin{bmatrix}a_{n-1}\\a_{n-2}\end{bmatrix}$（友矩阵）
> - $A^{n}=P\Lambda^{n}P^{-1}$，注意 $\Lambda^{n-1}$ 与初值向量的配合（本题指数是 $n-1$）
> - **等比增长的识别**：$a_{n+1}+b_{n+1}=3(a_n+b_n)$ 一行验算，比展开 $a_n,b_n$ 通项快得多

> [!warning] 复盘提示
> 坑一：递推式写错。特别注意"$1$ 个 $\beta$ 分裂成 $2$ 个 $\beta$ + $1$ 个 $\alpha$"意味着**总数从 $1$ 变成 $3$**，这一点直接决定答案的底数 $3$；若误写成"$1$ 个 $\beta$ 变成 $2$ 个 $\beta$"（丢掉那个 $\alpha$），总数就变成 $2^n$。
> 坑二：初值搞混。$a_0=1$（$t=0$ 只有 1 个 $\alpha$）、$b_0=0$、$a_1=b_0=0$；矩阵幂的指数是 $n-1$ 而不是 $n$。
> 坑三：算出 $a_n$ 的通项就以为做完了。(2) 问的是 $a_n+b_n$，还要用 $b_n=a_{n+1}$ 转成 $a$ 的式子再合并——**这个"$b_n=a_{n+1}$"的观察是本题的巧点**。
