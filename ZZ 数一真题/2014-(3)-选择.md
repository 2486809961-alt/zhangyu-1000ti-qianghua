# 2014 数一 (3)（选择）

> [!question] 题干
>
> 设 $f(x,y)$ 是连续函数，则
> $$\int_{0}^{1}\mathrm{d}y\int_{1-y}^{\sqrt{1-y^{2}}}f(x,y)\,\mathrm{d}x=(\quad)$$
> 四个选项都是把该积分改写成 $x$ 型累次积分或极坐标下的累次积分：(A)(B) 为直角坐标形式（其中含上限 $\sqrt{1-x^{2}}$ 的项可辨），(C)(D) 为极坐标形式，且 (C) 的面积元写作 $\mathrm{d}r$、(D) 写作 $r\,\mathrm{d}r$——各选项积分的具体上下限在原文中笔画粘连，(原文 OCR 无法辨认)。
> 另一路像素级 OCR 把内层下限读作 $-\sqrt{1-y^{2}}$（即 $\int_0^1\mathrm{d}y\int_{-\sqrt{1-y^2}}^{\,1-y}$，此时区域含左半圆、极坐标需按 $\theta=\frac\pi2$ 分段），本笔记采用上式的 $1-y$ 读法；两者答案同为 (D)，仅极坐标分段不同。

> [!success] 答案
>
> (D)（极坐标形式：$\displaystyle\int_{0}^{\pi/2}\mathrm{d}\theta\int_{\frac{1}{\cos\theta+\sin\theta}}^{1}f(r\cos\theta,r\sin\theta)\,r\,\mathrm{d}r$；原文各选项的积分限笔画粘连，(原文 OCR 无法辨认)，字母依积分区域判定）

## 解析

切入点：先把积分区域画出来。由 $0\leqslant y\leqslant1$、$1-y\leqslant x\leqslant\sqrt{1-y^{2}}$ 知区域是单位圆 $x^{2}+y^{2}\leqslant1$ 在第一象限中、直线 $x+y=1$ 上方的那块弓形，它关于 $x,y$ 对称，换成 $x$ 型积分时 $y$ 从 $1-x$ 到 $\sqrt{1-x^{2}}$，$x$ 从 $0$ 到 $1$。关键步骤：改用极坐标，射线 $\theta$ 从 $0$ 到 $\dfrac{\pi}{2}$，圆 $x^{2}+y^{2}=1$ 给出 $r=1$，直线 $x+y=1$ 即 $r(\cos\theta+\sin\theta)=1$，给出 $r=\dfrac{1}{\cos\theta+\sin\theta}$，故 $r$ 从 $\dfrac{1}{\cos\theta+\sin\theta}$ 到 $1$。于是原式 $=\displaystyle\int_{0}^{\pi/2}\mathrm{d}\theta\int_{\frac{1}{\cos\theta+\sin\theta}}^{1}f(r\cos\theta,r\sin\theta)\,r\,\mathrm{d}r$。考点：二重积分换序与极坐标变换，面积元必须带 $r\,\mathrm{d}r$。易错点：(C) 漏写雅可比因子 $r$（写成 $\mathrm{d}r$）是最典型的错误；把内层下限误取为 $0$ 会变成整个四分之一圆。原文该题选项的上下限不可辨，故以可读部分（$\pi/2$、$1/(\cos\theta+\sin\theta)$、$\sqrt{1-x^{2}}$）为准，原文缺失，依题意补全。
