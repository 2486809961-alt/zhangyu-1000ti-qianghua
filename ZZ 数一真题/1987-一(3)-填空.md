# 1987 数一 一(3)（填空）

> [!question] 题干
>
> 由曲线 $y=\ln x$ 与两直线 $y=(e+1)-x$ 及 $y=0$ 所围成的平面图形的面积是 ______．

> [!success] 答案
>
> $\dfrac{3}{2}$

## 解析

先把三条线的交点定下来：$\ln x$ 与 $y=e+1-x$ 在 $x=e$ 处相交（两边都等于 $1$）；$\ln x$ 与 $y=0$ 交于 $x=1$；直线 $y=e+1-x$ 与 $y=0$ 交于 $x=e+1$。区域下界都是 $y=0$，上界要分段：$x\in[1,e]$ 时取 $\ln x$，$x\in[e,e+1]$ 时取直线。于是 $S=\int_1^{e}\ln x\,dx+\int_e^{e+1}\big[(e+1)-x\big]dx$。第一项分部积分得 $\big[x\ln x-x\big]_1^{e}=1$，第二项是底为 $1$、高为 $1$ 的三角形，面积 $\dfrac12$。所以 $S=1+\dfrac12=\dfrac32$。考点是定积分的几何应用与分段拼接。最易错的是只算 $\int_1^e\ln x\,dx$ 而漏掉右端三角形，或把交点算成 $x=e+1$。
