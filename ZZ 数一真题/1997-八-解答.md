# 1997 数一 八（解答）

> [!question] 题干
>
> 设 $A$ 是 $n$ 阶可逆方阵，将 $A$ 的第 $i$ 行和第 $j$ 行对换后得到的矩阵记为 $B$．\n(1) 证明 $B$ 可逆；\n(2) 求 $AB^{-1}$．

> [!success] 答案
>
> $AB^{-1}=P$，其中 $P$ 是将单位阵 $E$ 的第 $i$ 行与第 $j$ 行对换所得的初等矩阵（且 $P=P^{-1}$）

## 解析

用初等矩阵刻画行变换：设 $P$ 为单位阵交换第 $i,j$ 行所得的初等矩阵，则 $B=PA$，且 $P^{2}=E$、$P^{-1}=P$、$|P|=-1\ne0$。(1) $P$ 与 $A$ 都可逆，可逆矩阵之积可逆，故 $B$ 可逆，且 $B^{-1}=(PA)^{-1}=A^{-1}P^{-1}=A^{-1}P$。(2) 于是 $AB^{-1}=A\cdot A^{-1}P=P$，即 $AB^{-1}$ 恰是那个“交换第 $i,j$ 行”的初等矩阵（它也是对换第 $i,j$ 列的单位阵）。考点是初等矩阵与初等变换的对应、逆矩阵的运算律；易错点是把 $B^{-1}$ 写成 $P^{-1}A^{-1}$ 从而得出 $AB^{-1}=P^{-1}A^{-1}A=P^{-1}$ 或 $P^{-1}A$ 之类——$(PA)^{-1}=A^{-1}P^{-1}$ 的顺序不能颠倒，且最后要说明 $P^{-1}=P$ 才能把答案写成 $P$。
