# 1999 数一 十二（解答）

> [!question] 题干
>
> 设随机变量 $X$ 与 $Y$ 相互独立，下表列出了二维随机变量 $(X,Y)$ 的联合分布律及关于 $X$ 和关于 $Y$ 的边缘分布律中的部分数值，试将其余数值填入表中的空白处。
>
> | $X\backslash Y$ | $y_1$ | $y_2$ | $y_3$ | $P\{X=x_i\}=p_i$ |
> |---|---|---|---|---|
> | $x_1$ |  | $\frac18$ |  |  |
> | $x_2$ | $\frac18$ |  |  |  |
> | $P\{Y=y_j\}=p_{\cdot j}$ | $\frac16$ |  |  |  |

> [!success] 答案
>
> $p_{11}=\frac1{24},\ p_{12}=\frac18,\ p_{13}=\frac1{12}$；$p_{21}=\frac18,\ p_{22}=\frac38,\ p_{23}=\frac14$；$p_1=\frac14,\ p_2=\frac34$；$p_{\cdot1}=\frac16,\ p_{\cdot2}=\frac12,\ p_{\cdot3}=\frac13$

## 解析

独立性把每个格子拆成“行边缘×列边缘”：$p_{ij}=p_i\,p_{\cdot j}$。由 $p_{21}=p_2p_{\cdot1}=\frac18$ 且 $p_{\cdot1}=\frac16$ 得 $p_2=\frac34$，从而 $p_1=\frac14$。再由 $p_{12}=p_1p_{\cdot2}=\frac18$ 得 $p_{\cdot2}=\frac12$，于是 $p_{\cdot3}=1-\frac16-\frac12=\frac13$。逐格相乘：$p_{11}=\frac14\cdot\frac16=\frac1{24}$，$p_{13}=\frac14\cdot\frac13=\frac1{12}$，$p_{22}=\frac34\cdot\frac12=\frac38$，$p_{23}=\frac34\cdot\frac13=\frac14$，而 $p_{21}=\frac34\cdot\frac16=\frac18$ 正与题给相符。最后按行、按列求和校验边缘分布。考点是独立性条件下联合分布与边缘分布的互推。易错：把题给的 $\frac18$ 当成边缘概率直接填进最后一行；填完不校验行列和，导致内部不自洽。
